# ЮНМ — Готова система за один вечір

Односторінковий лендинг реєстрації на безкоштовний вебінар про банерну монетизацію
YouTube Shorts та Reels (22 вересня, 19:00 за київським часом).

## Що всередині

- `index.html` — вся сторінка: розмітка, стилі, таймер і липка кнопка в одному файлі.
- `hero.jpg` — кадр із ведучими для першого екрана 789×941 (вирізаний з банера, без тексту).
- `cover.jpg` — повний банер 1200×675, використовується лише як прев'ю для соцмереж (og:image).

Збірка не потрібна: це статика. Локально достатньо відкрити `index.html` у браузері.

## Що треба оновити перед запуском

1. **Посилання реєстрації** — редірект `tg.pulse.is/unmveb_bot` з міткою
   `utm_source=site`. Якщо сторінку відкрито з `?utm_source=...`, скрипт унизу
   `index.html` підставляє це значення в усі три кнопки. Щоб мітка була видна
   в SendPulse, у боті має існувати змінна `utm_source`.
2. **Дата вебінару в таймері.** Внизу `index.html`, у скрипті:
   `new Date('2026-09-22T19:00:00+03:00')`.
3. **Домен.** `og:url` і `og:image` містять абсолютні посилання на
   `unm-landing-coral.vercel.app`. При переїзді на власний домен їх треба оновити.

## Анкета `/zayavka`

`zayavka/index.html` — форма заявки (ім'я, номер, нік у Telegram — необов'язковий).
Заявки дописуються в Google Таблицю: A — Ім'я, B — Номер, C — Нік.
Прийом робить Google Apps Script із `apps-script/Code.gs`.

Як підключити (один раз):

1. Відкрити таблицю → **Розширення → Apps Script**, вставити вміст
   `apps-script/Code.gs` замість коду за замовчуванням, зберегти.
2. **Розгорнути → Нове розгортання** → тип **Веб-застосунок**.
   Виконувати від імені: **Я**. Хто має доступ: **Усі**. Надати дозволи.
3. Скопіювати URL виду `https://script.google.com/macros/s/.../exec` і вставити
   його в `SCRIPT_URL` унизу `zayavka/index.html`.

Якщо змінюєте `Code.gs`, у редакторі треба зробити **Розгорнути → Керувати
розгортаннями → Редагувати → Нова версія**, інакше URL працюватиме зі старим кодом.
